## Scientific guardrails

এই বই IQ score বাড়ার নিশ্চয়তা দেবে না এবং “genius”, “10X brain” বা নির্দিষ্ট IQ-point বৃদ্ধির দাবি করবে না। Intelligence-কে reasoning, problem solving, learning, planning, language, memory, attention এবং adaptation-এর সমন্বিত construct হিসেবে উপস্থাপন করা হবে [1]। Working memory-কে সীমিত cognitive workspace হিসেবে ব্যাখ্যা করা হবে; এটি শেখা, comprehension, reasoning ও problem solving-এর সঙ্গে সম্পর্কিত হলেও training-এর transfer নিয়ে অতিরঞ্জিত দাবি করা হবে না [2]। Metacognition-কে নিজের cognitive process সম্পর্কে knowledge এবং তা monitor/control করার ক্ষমতা হিসেবে দেখানো হবে; evidence যেখানে mixed, সেখানে তা স্পষ্ট থাকবে [3]। Creativity-র ক্ষেত্রে novelty-এর পাশাপাশি usefulness, context, divergent–convergent movement এবং metacognitive monitoring রাখা হবে [4]।

## Page architecture and reader rhythm

প্রতি chapter-এর page range একটি production target। Chapter ছোট concept হলে prose সংক্ষিপ্ত থাকবে; গুরুত্বপূর্ণ concept হলে story, explanation, example, counterexample, exercise এবং visual-এর মাধ্যমে গভীরতা বাড়বে। কোনো chapter কেবল page পূরণ করার জন্য repeated definition বা generic motivation ব্যবহার করবে না।

| Rhythm element | ব্যবহার |
| --- | --- |
| Story / scene | abstract concept-এর আগে lived experience তৈরি করবে |
| Question | reader-এর intuition ও prior belief পরীক্ষা করবে |
| Surprise / counterexample | automatic conclusion নড়াবে |
| Explanation | সহজ বাংলায় mechanism পরিষ্কার করবে |
| Science note | claim-এর সীমা ও evidence status জানাবে |
| Example | student, teacher, worker, parent, business বা everyday life-এ transfer দেখাবে |
| Practice / reflection | reader নিজের চিন্তা observe করবে |
| Key insight | chapter-এর durable idea এক বাক্যে রাখবে |

## Visual system

Visuals decoration হিসেবে নয়, explanation-এর অংশ হিসেবে থাকবে। Attention-এর জন্য selection diagrams, memory-এর জন্য workspace ও retrieval maps, logic-এর জন্য argument maps, probability-এর জন্য calibrated scales, spatial intelligence-এর জন্য rotation frames, metacognition-এর জন্য object-level/meta-level diagrams এবং final synthesis-এর জন্য integrated thinking operating system ব্যবহার করা হবে।
